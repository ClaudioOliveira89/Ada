### This repository documents my learning and development journey with the Ada programming language, including practical projects and experiments.
![Ada](https://img.shields.io/badge/Ada-0d1117?style=for-the-badge&logo=Ada&logoColor=25fafe)&nbsp;

---
This repository was created for academic purposes to document my learning journey with the Ada programming language — a structured, strongly-typed, and compiled language designed for reliability in safety-critical systems, especially in the aerospace, defense, industrial, and real-time domains. The goal is to progressively explore key language features, including modular programming with packages, task-based concurrency, strong type systems, contract-based programming with SPARK, exception handling, and compilation control. <br>
This space serves as a foundation for notes, hands-on exercises, experiments, and small structured projects focused on disciplined, robust, and maintainable software development applicable to academic and professional high-assurance systems.

---
Este repositório foi criado com fins acadêmicos para documentar meu processo de aprendizado com a linguagem de programação Ada — uma linguagem estruturada, fortemente tipada e compilada, projetada para confiabilidade em sistemas críticos de segurança, especialmente nos domínios aeroespacial, de defesa, industriais e embarcados em tempo real. O objetivo é explorar progressivamente os principais recursos da linguagem, como modularização com pacotes, concorrência baseada em tarefas, sistema de tipos fortes, programação baseada em contratos com SPARK, tratamento de exceções e controle de compilação. <br>
Este espaço serve como base para anotações, exercícios práticos, experimentos e pequenos projetos estruturados, com foco no desenvolvimento de software disciplinado, robusto e sustentável, aplicável a contextos acadêmicos e profissionais de alta confiabilidade.
