## Repository created for programming and development in the Ada language.
![Ada](https://img.shields.io/badge/Ada-0d1117?style=for-the-badge&logo=Ada&logoColor=25fafe)&nbsp;

This repository was created for academic purposes to document my learning journey with the Ada programming language—a structured, strongly-typed language designed for safety-critical systems in military, aerospace, and industrial applications. The main goal is to gradually explore the core concepts of the language, including packages, safe data types, concurrency with tasks, formal contracts, and strict compilation control. This space will be dedicated to experiments, notes, exercises, and small projects, with a focus on building structured and safe programming practices applicable to both academic and professional environments where reliability is critical.

Este repositório foi criado com fins acadêmicos para documentar meu processo de aprendizado da linguagem Ada, uma linguagem estruturada, fortemente tipada e projetada para sistemas críticos que exigem alta confiabilidade, como aplicações militares, aeroespaciais e industriais. O objetivo principal é explorar gradualmente os conceitos essenciais da linguagem, como pacotes, tipos de dados seguros, concorrência com tarefas, contratos formais e controle rigoroso de compilação. Este espaço será dedicado a experimentos, anotações, exercícios e pequenos projetos, com foco em desenvolver boas práticas de programação seguras e estruturadas, aplicáveis tanto em ambientes acadêmicos quanto profissionais de alta criticidade.
